# DAVINCI 外部测试邀请文案

大家好，这里是 DAVINCI 的首轮测试版。

这是一款本地照片调色 CLI 工具，你给它一张照片，它会先给你看几个方向，再让你决定。当前内置了 Leica 和 Fuji 两套风格路线。

这次测试包已经做成了可直接运行的 macOS 独立版，不需要自己装 Python。打开方式很简单，双击 `DAVINCI.command` 就可以。

这轮我们主要想看 4 件事：

1. 第一次打开是否顺畅
2. 激活流程是否容易理解
3. Leica / Fuji 的选择是否清楚
4. 预览和保存流程是否稳定

成片默认会保存在 `~/Pictures/DAVINCI/`，原图不会被覆盖。

如果 macOS 第一次提示“无法打开”，请右键 `DAVINCI.command`，选择“打开”，再确认一次即可。

如果你愿意帮忙测试，遇到任何问题都欢迎直接把这几项发给我：

- 你的机型
- macOS 版本
- 你做了什么
- 实际发生了什么
- 终端截图或报错

非常建议优先帮我们看首次使用链路：

- 打开
- 进入首页
- 激活
- 选 Leica / Fuji
- 预览
- 保存

谢谢，等你们的真实反馈。
