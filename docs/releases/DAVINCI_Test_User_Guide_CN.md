# DAVINCI 测试版使用说明

## 你会拿到什么

一个可直接运行的 DAVINCI 独立包。你不需要自己安装 Python。

## 适用系统

- macOS
- Apple Silicon 芯片

当前这轮公开测试只支持这一种环境，`Windows / Linux` 不在本轮支持范围内。

## 如何打开

推荐双击：

- `DAVINCI.command`

如果你习惯命令行，也可以在终端里进入文件夹后运行：

```bash
./davinci
```

## 如果你要用一条命令安装

如果发布方已经给了 `install.sh` 地址和 zip 地址，你可以直接运行：

```bash
curl -fsSL "https://你的地址/install.sh" | DAVINCI_RELEASE_URL="https://你的地址/davinci-macos-v1.zip" sh
```

安装完成后，通常可以直接运行：

```bash
davinci
```

## 如果 macOS 拦截

第一次打开如果看到“无法打开”或“来自未知开发者”：

1. 右键 `DAVINCI.command`
2. 选择“打开”
3. 在弹窗里再次选择“打开”

这是正常现象，因为当前测试版还没有做正式签名和 notarization。

## 首次使用流程

1. 启动后先看到 DAVINCI 首页
2. 你可以直接回车看演示，或者输入 `1` / `2`
3. 第一次真正开始处理前，会要求打开官网完成一次激活
4. 激活后继续处理，不需要重来

## 怎么开始

- 直接回车：先看演示
- 输入 `1`：先看 Leica 风格
- 输入 `2`：先看 Fuji 风格
- 拖入照片：直接开始
- 粘贴照片路径：直接开始

## 成片保存位置

- 正式结果：`~/Pictures/DAVINCI/`
- 演示结果：`~/Pictures/DAVINCI/_demo/`

原图不会被覆盖。

## 希望你重点帮我们看什么

- 首次打开是否顺畅
- 激活流程是否容易理解
- 选 Leica / Fuji 后是否清楚
- 滤镜预览窗口是否稳定
- 结果保存位置是否容易找到
- 是否有卡住、转圈、无响应、无法关闭的情况

## 反馈时请尽量带上这些信息

- 你的机型
- macOS 版本
- 你点了什么
- 你输入了什么
- 出现了什么现象
- 如果有报错，把终端最后几行发来
